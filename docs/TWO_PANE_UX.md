# 두 화면 UX — 안드로이드 태블릿·아이패드·폴드 펼침 (2026-11-01, 사용자 지시)

한자유니버스의 규칙(`docs/DUAL_SCREEN_UX_from_hanja.md`)을 그대로 따른다. 확인 캡처: 아이패드 Pro 11 시뮬레이터(세로).

## 1. 기준 하나

- `isWide(context)` = 가로 **720 논리픽셀 이상** (`lib/core/theme.dart`). 아이패드 세로·가로, 안드로이드 태블릿, 갤럭시/아이폰 폴드 펼침(세로 ≈740). 접은 폴드·폰은 한 화면.
- 회전: 짧은 변 600 이상이면 가로 허용, 아니면 세로 고정 (`main.dart` `_setOrientations`, 폴드를 접고 펼 때마다 다시 계산).

## 2. 탭 4개(배우기·복습·탐색·나) — 한자앱과 같은 구조 (2026-11-02 사용자 지시 "아이패드 UX 완전히 변경, 한자세션 참고")

- 앱바(워드마크 「일본어유니버스」 + 검색) 아래. 폰: 하단 `NavigationBar` + 탭 내용 전체 화면. 넓은 화면(`lib/screens/main_screen.dart`): `NavigationRail`(900 미만이면 선택된 라벨만) + 왼쪽 칸 `(w*0.34).clamp(300, 440)` 에 탭 목록 + 오른쪽 칸(자기 `Navigator`, 빈 자리 안내). **두 칸까지만.**
- **배우기** `LearnTab`: 인사·연속 일수 → 오늘의 학습 카드(첫 미완료 에피소드) → 기초(50음도·조사·한자 단계·회화 허브 — 오른쪽 칸) → 에피소드 단원 L1~L3(필터, 단원은 전체 화면).
- **복습** `ReviewTab`: 문장 플래시카드(랜덤 20, 전체 화면)·복습 덱 5·한자 퀴즈·조사 테스트.
- **탐색** `ExploreTab`: 검색 + 한자(사전·한자음·발음부)·단어(JLPT·필수·빈도·외래어) — 참고 자료는 오른쪽 칸.
- **나** `MeTab`: 진행·달성률(오른쪽 칸) + `ProfileScreen(embedded: true)`.
- 화면 열기 = `openPane(context, builder)` (`lib/core/pane.dart`): 오른쪽 칸이 있으면 거기(왼쪽에서 열면 칸 교체, 오른쪽 안에서 열면 쌓임), 없으면 push. 오른쪽 칸 안의 화면이 하는 보통 `Navigator.push` 는 그대로 그 칸 안에 쌓인다.
- 뒤로: `NavigatorPopHandler` 가 오른쪽 칸 Navigator 에 먼저 보낸다. 줄 카드(`_NavRow`)·단원 행은 제목 말줄임으로 300 폭에서도 안 깨진다.
- 옛 홈(인사 + 12개 메뉴 그리드)·학습 탭·진행 탭·프로필 탭은 위 4탭으로 흡수(화면 파일은 그대로, 진입만 바뀜).

## 3. 학습은 전체 화면, 넓으면 대화 | 카드 반씩

- `openFull(context, builder)` = 루트 Navigator push. 에피소드(홈 오늘의 학습·학습 탭·회화 허브), 플래시카드 덱 세션, 한자 퀴즈, 조사 테스트가 쓴다 — 왼쪽 목록을 감춘다.
- 에피소드(`episode_screen.dart`): 폭 720 이상이면 `Row` — 왼쪽 = 대화 버블, 오른쪽 = 고른 턴의 문장 카드(`SentenceFlashcardScreen(embedded: true)`). 버블을 누르면 **새 화면이 아니라 오른쪽 반만** 그 카드로 바뀌고(버블에 금색 테두리), 카드에서 몰라요/공부중/알아요를 누르면 `onProgress` 로 왼쪽 학습 표시가 바로 갱신된다. 좁으면 전처럼 카드 화면으로 push.
- 버블 최대 폭은 `MediaQuery` 가 아니라 실제 칸 폭의 74% (`LayoutBuilder`).

## 4. 확인 방법

- `python3 tools/pane_shots.py <아이패드 UDID> <출력폴더>` — `integration_test/two_pane_test.dart` 를 `flutter drive` 로 돌리며 `SHOT:` 마다 시뮬레이터 캡처(배우기·탐색+사전 칸·조사 칸·에피소드 분할·카드 전환·복습·나 7장). 가로는 시뮬레이터가 프로그램으로 회전이 안 되니 실기기(TestFlight)로.
- 단위 테스트는 폰 크기 기준 — 두 화면 분기를 타지 않는다.

## 5. 남은 것

- 진행·프로필 탭 안 화면이 왼쪽 칸(300~460)에서 넉넉한지 폴드 폭(≈740)으로 한 번 더 확인.
- 한자 퀴즈·덱 세션 카드가 아주 넓은 화면에서 과하게 커지지 않게 폭 제한(아직 전체 폭).
