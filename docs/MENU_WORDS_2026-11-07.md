# 2026-11-07 단어·메뉴 개편 — 다른 언어 앱에 같이 적용할 것

일본어 앱(talkverse-ja)에서 사용자 지시로 바꾼 것. 다른 언어 세션은 자기 앱에 같은 구조로 반영한다. 숫자는 언어마다 다르니 자기 절벽 산출값을 쓴다.

## 1. 절벽 단어 화면 (`lib/screens/word_freq_screen.dart`)

- **R5 는 2,000위에서 끊는다.** 2,500 → 2,000(일본어 2,000위 누적 87.4%). 성과의 다음 절벽 상한도 2,000.
- **20어 = 한 단원.** 선택한 구간(전체·R1~R5)의 단어를 순위 순으로 20개씩 묶어 「1단원 · #1-20 · R1」 머리줄 + 격자.
- **단어는 네모 타일**(세로 나열 금지). 타일 = 순위(또는 会)·읽기 · 그림(있으면) · 단어 · 뜻 한 줄. 탭하면 발음. 칸 수 = 화면 너비 ÷ 112(3~8칸).
- **버튼 2개: 「절벽구간 단어만」 / 「회화 단어 포함 (+N)」.** 포함이면 회화 전 편의 레마 중 **2,000위 밖이면서 단어 DB에 있는 것**이 「회화」 구간으로 뒤에 붙는다(구간 칩에 「회화」 추가). DB 는 합치지 않는다 — 빈도표와 회화 레마 목록을 화면에서만 합친다.
  - 목록 생성: `tools/freq/conv_words.py` → `assets/data/freq/conv_words_ja.json` `{words:[{word,kana,ko,n}]}`(등장 횟수순). 등장 인물 이름·연출 지시어(小声·爆笑 등)는 뺀다.
- 뜻·읽기는 단어 DB(`WordService.byLemmas`)에서 표면형 일치로 붙인다. 없으면 단어만.

## 2. 한자(문자) 기준 절벽 재산출 — 문자 체계가 있는 언어(일본어·중국어)

- 단어 절벽과 **같은 말뭉치·같은 공식**(누적 55/60/70/80% 첫 순위 → R1~R4, 80% 밖 R5)으로 **글자 하나 = 토큰 하나**로 다시 셌다. `tools/corpus/cliff_kanji_ja.py <zip> <출력> --only <목록>`.
- 일본어 결과: **R1 171 · R2 217 · R3 340 · R4 532**(2,000위 누적 98.9%, 2,500위 99.6%). `data/corpus/cliff_v2/kanji_ja_top2500.csv`, `ja_kanji_cliff_summary.json`.
- 앱 반영: 한자 DB(`kanji_db.json`)의 rank/pct 를 새 표로 교체(1,921자), `version.json db` 올려 재시딩. 경계는 **코드 한 곳**(`KanjiIndexService.regionOf`)에 두고 한자 단계·발음부·성과가 모두 그걸 쓴다. 옛 294/437/998 전부 삭제.

## 3. 「앱 소개」 페이지 (`lib/screens/about_screen.dart`)

- 두 화면(가로 720↑) 왼쪽 **레일 맨 아래** `NavigationRail.trailing` 에 ⓘ 「앱 소개」. 폰은 프로필 → 정보 → 「앱 소개」.
- 내용: 머리글(처음 62어 = 55%, 778어 = 80% …「절벽」) → **1. 단어 기준**(R1~R5 표: 순위 범위·개수·누적%) → **2. 한자 기준**(같은 표) → **3. 산출 방식**(말뭉치 규모·빈도 정의·절대 기준 4비율 = 19개 언어 공통) → **4. 앱에서 쓰는 곳**(절벽 단어·한자 배우기·성과). 막대는 구간 등폭 5칸.
- 공개 저장소 규칙: 말뭉치 제공처·작품 이름은 적지 않는다("일본 제작 영화·드라마 대사 200편"까지만).

## 4. 메뉴 정리 (`lib/screens/main_screen.dart`, `profile_screen.dart`)

- 배우기: **기초**(50음도, 한자 배우기) → **문법**(조사 — 새 섹션) → **회화**(주제별 회화, 맞춤 회화) → **단어**(절벽 단어 R1~R5 · JLPT 단어) → 에피소드 → **참고**(패밀리 한자 — 맨 아래).
- 삭제: 「필수 단어」(Day별 975어), 「한자 단계」(JLPT 4지선다 — 복습 탭의 한자 퀴즈는 유지), 옛 「회화」(Conversation), 프로필의 「앱 업데이트」 타일(배포는 스토어·TestFlight).
- JLPT 단어 부제는 총수가 아니라 **급별 수**: `N5 735 · N4 676 · N3 2,135 · N2 1,744 · N1 2,698`(「8,600어 · 후리가나」 폐기).
- 탭 「나」 → **「프로필」**. 프로필에서 데이터 통계(회화 턴·한자 DB·단어 수)·메모 내보내기·TTS·테마·Stack 줄 삭제. 남는 것: 계정 · 성과 · 기록(학습 기록 초기화) · 학습자 프로필(이름·성별) · 설정(언어) · 정보(앱 소개·버전·저작권).

- 태국어앱: 메뉴 **「문장 말하기」**(이름에 '발음' 없음), 부제 「한글 보고 태국어로 · 7초/4초/2초」, 화면 제목 「문장 말하기」/「한국어 보고 태국어로 말하기」, 홈 메뉴 그리드 두 번째 칸(회화 다음) + 퀵메뉴. 판정 안내 「발음 품질은 보지 않아요」(단어 포함 여부만).

## 6. 문장 레마 탭 → 단어창 · 후리가나 전역 토글 (2026-11-07 저녁 추가)

- 회화 문장(`lib/widgets/selectable_ja_text.dart`)을 **레마(내용어) 단위**로 쪼개 **탭하면 단어창**(단어 DB `byLemmas`). 단어장에 없는 레마는 그 글자가 한자면 한자 시트. **길게 누르면 한자 시트**(레마 안 한자). 레마 밖 한자는 탭 → 한자 시트(이전과 같음). 단어장에 있는 레마는 밑줄 색을 다르게(ai) 표시.
- **후리가나는 레마 읽기로 얹는다** — 표면형 앞뒤 가나(접두 お·오쿠리가나)를 읽기에서 떼고 한자 토막 위에만 루비. 문자 체계가 없는 언어는 해당 없음(한국어 발음 표기 등 자기 식 "읽기 보조"로 치환).
- **전역 설정 `LearnerPrefs.furigana` — 기본 미표시.** 앱바 버튼 「ふ」(`lib/widgets/furigana_toggle.dart`) 를 회화·그림 카드·두 화면 스크립트 머리줄·JLPT 단어·절벽 단어에 두고, 프로필 → 설정에도 한 줄. **표시로 켤 때 스낵바 「힘들어도 후리가나를 보지 않고 익혀보세요」**(사용자 지시).

## 7. 회화 감정 열 · 어조사 이모지 (2026-11-07 밤, uk 경유 사용자 지시, 모든 언어)

- **감정 열을 회화문과 함께 쓴다.** 턴마다 `emotion`(한 감정) 또는 `segs`(`[감정, 본문(, 읽기)]`, 감정이 바뀌는 턴), 고정 인물 밖 화자는 편 `cast`, 자리 표시 값은 편 `fill`. 감정은 `data/tts/PLAN_GUIDE.md` 의 16개, neutral 일색 금지.
- **음성 스크립트가 그 감정을 쓴다 — 손으로 두 번 적지 않는다.** `tools/tts/plan_from_ep.py` 가 편 JSON → 감정 계획(`data/tts/plan/<편id>.json`)을 만들고, `ttslib.plan()` 이 계획 파일이 없으면 자동 생성하므로 `make_jobs.py`·`run_all.py` 가 그대로 돈다. `check_dialogues.py` 가 감정 없는 턴·segs≠본문·neutral 과반을 잡는다. 215편 계획을 감정 열로 옮겨 되돌려 만들었을 때 전부 일치.
- **어조사 이모지(한국어·중국어·일본어·태국어·베트남어)**: 문장 끝 어조사(일본어 ね·よ·な·わ·ぞ·かな·じゃん·でしょ·のに·ねん… ; 물음 か·の 는 감정이 뚜렷한 턴만)로 끝나는 문장이 있는 턴에 **감정과 어울리는 이모지 하나**를 `emoji` 열로 넣는다(`tools/particle_emoji.py`, 감정 → 이모지 표 16개). **본문·읽기·음성은 건드리지 않는다** — 앱은 `DialogueTurn.shown`(= ja + 이모지)으로 화면에만 붙이고 TTS 는 ja 를 읽는다. 리뷰 페이지도 같은 식. **기존 회화에도 적용**(일본어 215편 426턴, 음성 재생성 없음).
