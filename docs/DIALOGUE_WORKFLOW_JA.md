# 회화 제작 워크플로 (일본어앱) — 다른 언어 세션에 넘기는 프롬프터

2026-11-02 사용자와 일본어앱 세션이 S1·S2 를 만들며 정한 **현재 규칙 한 벌**. 이 문서를 고칠 때는 덧붙이지 말고 전체를 다시 쓴다(사용자 지시: 누더기 메모 금지). 설계 원본은 `docs/DIALOGUE_DESIGN_JA.md`, 공통 원칙은 https://talkverse.uk/talkverse/dialogue-rules/ .

## 1. 목표 — "우리 회화 톤" (사용자가 S1·S2·연애1 을 통과시키며 준 기준)

- **학습자가 암기하고 싶어지는 대사**를 쓴다. 기억하기 쉽게: 한 턴은 짧은 한두 문장, 편마다 입에 남는 한 줄(「完全に面接じゃん！」「帰りたくない、ってこと」「はい、お願いします」)이 있어야 한다.
- **킥(웃음·놀람 포인트)은 코믹하게, 매 편 1개 이상.** 현실에서 일어날 법한 사고: 반사적으로 はい 해 버려 젓가락·스푼·빨대를 다 받음, 배운 단어로 주문했다가 「ホイップなしで」, 90도 인사가 「면접」, 「何が好き?」가 고백으로 읽힘, 고백 순간 편의점 자동문 「温めますか？」(앞 편 콜백). 킥이 약하면 다시 쓴다.
- **연애 편에는 설렘·두근거림·상상을 자극하는 여백**: 「終電、逃してもいいかな」 「言わせないで」 「嬉しいかも」처럼 말을 다 하지 않고 멈추는 대사, 침묵(…) 한 턴, 끝의 여운(「楽しみ」). 성적 묘사는 없음(iOS 12+).
- 학습자가 입으로 따라 하는 순간 "진짜 일본 사람 말"이라고 느껴야 한다. 교과서체·번역투·설명하는 대사·정리된 느낌(AI 지문) 금지. 다짐·감사 인사로 끝내는 대사 금지(일본인의 미지근한 반응 「ちょっと意識してみる」가 더 진짜).
- 턴 수는 8(R1 기준, R2 8~12, R3 12~16). 턴 수를 늘리지 말고 **문장을 조금 길게**(1~2문장). Grok 재작성에 "지나치게 깎지 말 것"을 명시한다.
- 최우선 노출: 일본 사람이 실제로 많이 쓰는 짧은 표현(大丈夫です·いりません·もう一度お願いします·めっちゃ·じゃん·そうそう·てか·マジで? …). 표현 풀 `data/expressions/top_expressions.csv` 에 Grok 이 추천한 것을 계속 추가한다(현재 162개).
- 주인공 A 는 국적·이름 비고정(`{name}`·`{country}`·`{city}` 변수). 상대 B 는 주제마다 고정 인물(친구 유카, 사랑 사쿠라, 점원 C). 콜백(앞 편 대사를 다른 장면에서 재사용)과 leitmotiv(같은 단어 반복)는 옛 마스터 메모(2026-04)의 기법 그대로 쓴다.

## 2. 파이프라인 (한 편 = 한 바퀴)

1. **초안** — 이 세션이 JSON 으로 쓴다(`tools/prompts/dialogue_r1.md` 체크리스트, 장면·반전·목표 표현 포함).
2. **검사기** — `python tools/check_dialogues.py --fix-rd <파일>`: 턴 수·단어 수(R1 짧은 편 2~9, 긴 편 1~10, 채팅 1~7)·새 단어 ≤3/턴·표현 풀 ≥2(가나 낱말 경계로 셈)·반전·독음(한글) 자동 채움. 오류 0 이 될 때까지 초안을 고친다. 1단어 턴은 반전 턴·마지막 펀치라인·표현 풀 한마디·변수만인 턴에 허용. "앞 편 단어 재사용 ≥ 절반"은 장면이 바뀌면 비현실적이라 **경고(통계)**로만 둔다.
3. **Grok 재작성** — 초안을 그대로 주고 "실제 일본 사람 말로 다시 써 달라"고 한다(`tools/prompts/rewrite_grok.md`). **판정만 받는 검수는 쓰지 않는다**: 3회차에 "8줄 모두 이상 없음"이 나와도 AI 지문은 남는다는 사용자 판단. Grok 이 쓴 문장을 베이스로 삼아야 지문이 지워진다.
4. **최종 수정** — Grok 재작성본을 JSON 에 넣고 검사기 통과용으로만 최소 수정(단어 수·새 단어·독음). 뜻·말투를 다시 바꾸지 않는다. `review` 필드에 어느 회차를 반영했는지 한 줄.
5. **사용자 리뷰** — 아래 §4 형식으로 출력. 5분 안에 답이 없으면 다음 편으로 진행하되, **샘플 6편 단계에서는 S1·S2 → 리뷰 → 3편째** 순서로 한 편씩 확인받는다.
6. Gemini 방언·소수언어 검수는 **일본어에서는 하지 않는다**(사용자 결정). 다른 언어는 `tools/prompts/review_gemini.md` 틀을 참고.

## 4. 사용자 리뷰 출력 형식 · 게시

- 채팅 보고: 편 제목·장면·말투 한 줄 뒤, 턴마다 **세 줄**(일본어 / 한글 독음 / 한국어). 표 대신 줄로(모바일). 그 아래 Grok 이 바꾼 이유 요약과 추천 표현. 한국어가 없으면 사용자가 리뷰할 수 없다.
- **리뷰 페이지**: `python tools/review_html.py data/review/REVIEW_ja.html <편.json ...>` 로 자체 완결 HTML 생성 → talkverse.uk 세션에 "REVIEW_ja 갱신" 한 줄 전송 → https://talkverse.uk/talkverse/review/ja/ 에 재배포(uk 의 `tools/publish_review.sh ja`, noindex). 통과 편은 JSON `approved` 에 날짜를 적으면 초록 배지로 표시. 마크다운 시트는 `tools/review_sheet.py`(파일 전송용).
- 리뷰 입력: 페이지의 턴마다·편 제목 아래 입력칸 + 저장 버튼(2026-11-03 사용자 지시). 저장은 `https://talkverse.uk/api/review/ja`(uk 세션, POST {key,text,at} / GET 전체) + localStorage 백업. key = `편id:턴번호` 또는 `편id:all`(편 전체 — 턴이 너무 짧다 등). 이 세션은 GET 으로 읽어 편을 고치고, "통과"면 JSON `approved` 기록. 채팅으로 주는 한 줄 리뷰도 그대로 유효.

## 5-1. 참고 회화책 — 사용자 소장 영어 회화 교재 1권(사용자 지시 2026-11-02 "이 책을 참고"; 공개 저장소라 서명·출처는 적지 않음)

**단, 이 책에 매몰되지 않는다 — 우리 원칙(§1, 공통 원칙 14개, 8턴·짧은 표현 최우선·변수 주인공)이 우선이고 책은 문체 참고일 뿐**(사용자 지시 2026-11-02 새벽).

60일 × 회화 1편(9~16턴, 772쌍) 전체를 읽음(2026-11-02). 두 인물의 일상 장면에 늘 **작은 갈등·놀림·플러팅**이 있고 마지막 줄이 펀치라인이다. 가져올 것은 **문체·구조**만(내용·문장은 쓰지 않음, 저작권):
- **구조**: 질문 → 대답 + 이유나 농담 한 마디 → 상대가 그 말을 받아 되치기(「Was I that obvious?」「Yes, and I like it」). 설명 대신 반응으로 정보가 나온다. 중반에 오해·놀림·내기·흥정 같은 작은 갈등이 생기고, **끝 줄은 짧은 한 방**(「Oops, busted!」「Now you are talking!」「You are such a drama queen」「Deal!」).
- **턴마다 관용구·추임새 1개**(「You can say that again」「tell me about it」「no can do」「sell like hotcakes」「Dream on」). 일본어 대응 = それな·言えてる·マジで·やばい·〜じゃん·てか·さすが·うそ·ないない·まあね·だよね·知らんけど 등 — 표현 풀에서 고른다.
- **연애·설렘의 문법**: 작업 멘트와 그에 대한 반응(「Are you trying to be funny?」→「I'm very serious」), 질투 추궁과 변명, 「데이트야?」 확인, 「다시는 안 늦을게」 다짐과 「철 좀 들어」, 폰 비밀번호 사건(「John 이 왜 이렇게 많아?」). 설렘은 **상대가 자기 마음을 들키는 순간**에서 나온다 — 우리 연애 편의 「言わせないで」「嬉しいかも」와 같은 결.
- **길이**: 한 턴 1~3문장. 긴 설명 턴도 있지만 바로 다음 턴이 짧게 받아친다(긴/짧은 교대). 우리는 R1 은 8턴·1~2문장, R2·R3 는 12~16턴·1~3문장으로 따른다.
- **한국어 번역**: 직역 금지, 한국 사람이 실제로 하는 말(「저 피자라면 환장하는 사람이에요」「드라마 좀 그만 찍지」「딱 걸렸네!」). 우리 ko 도 같은 수위로 쓴다.
- **인물**: 매 편 성격이 대사로 드러난다(잘난 척, 투덜이, 마마보이, 쇼핑중독). 우리 고정 인물(유카·사쿠라·점원)에게도 성격 한 줄을 정해 두고 일관되게 쓴다 — 사쿠라 = 놀리기 좋아하고 먼저 마음을 들킴, 유카 = 직설·めっちゃ 남발, 점원 = 매뉴얼 그대로인데 타이밍이 기막힘.
