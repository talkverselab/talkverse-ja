# 학습자 맞춤 회화 생성 — 학습목적 × 도메인 (사용자 결정 2026-11-01)

**용도: 회화(대화) 생성의 축.** 학습자가 고른 학습목적과 도메인을 조합해 그 사람에게 맞는 회화를 만든다
(UI 를 바꾸는 "맞춤 포인트" 같은 것은 없다 — 사용자 2026-11-01). 구현 전 — 이 문서가 목록의 SSOT.

## 3. 목적 → 기본 도메인 (목적을 고르면 미리 켜 두는 도메인, 학습자가 바꿀 수 있음)

회화 생성 입력 = 목적 1 + 도메인 ≤3 + 장면(§2 세부값) + 수준(§4). 같은 장면이라도 목적이 다르면 말투·어휘가 다르다(예: 식당 — 여행이면 주문·계산, 취업이면 접객 쪽).

| 목적 | 기본 도메인 |

| travel | 여행 · 생활 |
| exam_jlpt · exam_other | 학업 · 생활 |
| study_abroad | 학업 · 생활 · 친구 |
| work_japan | 일 · 생활 |
| media | 문화콘텐츠 · 친구 |

## 4. 수준·제약 (회화 생성 때 함께 넣는 값)

- 현재 수준: 입문(가나 전) / 초급(N5~N4) / 중급(N3~N2) / 고급(N1+) — 배치 테스트로 추정
- 목표 기한: 1·3·6개월 / 1년 / 없음 → 하루 분량 계산 · 하루 시간: 5 / 15 / 30 / 60분
- 표시 언어: 한국어 / English / 日本語 / 中文(있음) · 한자 배경: 한국 한자 아는 사람(한자음 대응) / 모르는 사람(한자앱 GIF·형성자 경로)
- 음성 비중: 듣기·말하기 우선 / 읽기·쓰기 우선

## 5. 미정

- 첫 실행 때 고르게 할지(한자앱 목적 화면 식) / 프로필에서만.
- 20개 언어앱 공통 목록으로 고정할지(언어별 가감 — 예: 베트남어 `결혼이민`).
- 태그 저장 위치: 번들 JSON(지금) → 공용 `talkverse-db`(`docs/CLOUDFLARE_MIGRATION.md` §2).
