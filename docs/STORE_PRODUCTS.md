## App Store Connect

- 구독 3개(`lang_ja_1m`·`_3m`·`_1y`)는 **구독 그룹 하나**(예: 「일본어 유니버스」)에 넣는다 — 같은 그룹이라 업그레이드·다운그레이드가 스토어에서 처리된다. `all_1y` 는 **모든 언어앱에서 같은 ID** 를 쓰므로 그룹 운영 방식(앱마다 등록할지, 공용 처리할지)은 uk·서버(`/me/purchases`)와 맞춘다.
- 비소모성 2개(`lang_ja_life`·`all_life`).
- 각 상품: 현지화 이름·설명, 가격, 심사용 스크린샷(결제 시트), 심사 메모(「맞춤 회화 2편째부터 잠금, 결제 시트는 설정 및 프로필 → 이용권」).
- 앱 정보에 이용약관(EULA) `https://talkverse.uk/terms/`, 개인정보처리방침 `https://talkverse.uk/talkverse/ja/privacy/`.
- 옛 평생 상품 `com.talkverse.japaneseUniverse.lifetime` 을 이미 만들었다면 판매 중지(앱은 복원 시 `lang_ja_life` 로 인정한다).

## Google Play Console

- 정기 결제 3개 + `all_1y`: 정기 결제 상품마다 기본 요금제(base plan) 1개(자동 갱신, 기간 1개월/3개월/1년). 무료 체험·할인 없음.
- 인앱 상품(일회성) 2개: `lang_ja_life`·`all_life`.
- 옛 상품 `lang_ja` 가 있으면 비활성화.
- 앱 콘텐츠 → 개인정보처리방침 URL, 데이터 보안 양식(수집: 이메일·이름·계정 ID — 로그인 시만, 광고·분석 없음).

## 남은 일(서버·uk)

- 서버 `/me/purchases` 가 새 ID 6개를 알아야 한다: 구독은 만료일(스토어 확인)까지, `all_*` 는 모든 언어 이용권. 앱은 구독을 기기에서 「구매 시각 + 기간 + 3일」까지만 열고, 계정 이용권(`Account.has('ja')`)을 최종으로 본다.
