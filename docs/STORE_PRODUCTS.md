# 스토어 상품 등록 목록 — 일본어 유니버스 (2026-11-09 최종 가격)

가격은 사용자 최종 확정(2026-11-09) `~/talkverse/PRICING.md` 의 **앱 정가 / 앱 할인가**. 원본 문서는 talkverse-uk(`docs/legal/`)가 가지고, 이 파일은 일본어앱 사본이다 — 바꾸면 uk 에 알린다. **등록은 사용자가** App Store Connect·Google Play Console 에서 한다. 출시 순서는 한자앱 → 일본어(다음 후보) — 일본어 심사 제출은 uk 공지 뒤.

스토어 판매가 = **할인가**(출시 기념·정기 할인 30%). 앱 결제 시트는 정가를 취소선으로, 스토어 가격을 크게 보여 준다(`lib/main.dart` `Purchase.configure`, `lib/screens/paywall_screen.dart`). 정가 기간을 정기적으로 둔다(과장 할인 표시 방지) — 정가 기간에는 스토어 가격을 정가로 올리고 앱의 `krw` 도 정가로 바꾼다. 앱 안에서 사이트 가격을 안내·유도하지 않는다.

## App Store Connect

- 구독 `lang_ja_1m`·`_3m`·`_1y` 는 구독 그룹 하나(「일본어 유니버스」). `all_1y`·`all_life` 는 모든 언어앱이 같은 ID 를 쓰므로 등록 방식(앱마다 등록 / 공용 처리)과 서버 인정 방식은 uk 와 맞춘다.
- 상품마다 현지화 이름·설명, 가격, 심사용 스크린샷(결제 시트), 심사 메모(`docs/store/review_notes.md`).
- 앱 정보: 이용약관(EULA) https://talkverse.uk/terms/ · 개인정보처리방침 https://talkverse.uk/talkverse/ja/privacy/
- 옛 평생 상품 `com.talkverse.japaneseUniverse.lifetime` 을 만들었다면 판매 중지(앱은 복원 때 `lang_ja_life` 로 인정).

## Google Play Console

- 정기 결제 4개(`lang_ja_1m`·`_3m`·`_1y`, `all_1y`): 상품마다 기본 요금제 1개(자동 갱신, 1개월/3개월/1년), 무료 체험 없음.
- 인앱 상품(일회성) 2개: `lang_ja_life`·`all_life`. 옛 `lang_ja` 가 있으면 비활성화.
- 앱 콘텐츠: 개인정보처리방침 URL, 데이터 보안(`docs/store/data_safety.md`).

## 서버

- `/me/purchases` 가 새 ID 6개를 인정해야 한다(구독 = 스토어가 확인한 만료일까지, `all_*` = 모든 언어). uk 가 붙인다. 앱은 구독을 기기에서 「구매 시각 + 기간 + 3일」까지만 열고 계정 이용권(`Account.has('ja')`)을 최종으로 본다.
