## C. 책과 우리 원칙이 어긋나는 점 (참고)

- 책은 **카드에 모국어를 두지 말라**(번역이 단어의 "음악"을 지운다) — 우리 콘텐츠는 한국어 번역·note 고정(공통 원칙 §8). 절충 = 카드 **앞면에서만** 한국어를 숨기고 뒷면·에피소드에는 둔다.
- 책은 **카드를 직접 만들어야** 효과(남의 카드는 불확실성) — 앱이 카드를 주는 구조라 "내 힌트·내 이미지·내 문장" 칸으로 개인화를 보충(A3·B4·B9).
- 책의 625 단어는 영어 기준 구체어 — 우리는 절벽 R1 294어·한자 140자가 기준. 625 대신 **R1 구체어 부분집합**을 "그림 덱"으로.
