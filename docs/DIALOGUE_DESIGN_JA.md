# 일본어 유니버스 새 회화 설계안 — 주제·연쇄·최우선 표현 (2026-11-02, 초안 v1)

사용자 결정: 기존 회화(L1 ep1 40턴)는 쓰지 않고 **출시 수준으로 레벨별 회화를 처음부터** 만든다. 근거 = 공통 원칙(`DIALOGUE_RULES.md`, 사이트 게시본) + 『학습 원칙』 적용 결정 + 사용자 최우선 지시(§0-1).
이 문서는 **설계**다. 사용자가 확정하면 ① 최우선 표현 표 → ② 검사기 → ③ R1 주제부터 작성 순으로 간다.

## 0. 세 가지 뼈대

| 뼈대 | 한 줄 |
|---|---|
| **최우선 표현** | 일본 사람이 정말 많이 쓰는 짧은 구어·채팅 표현 120개를 "표현 풀"로 두고, **모든 편에 2개 이상**, 레벨이 올라도 계속 재등장 — 다른 규칙보다 앞선다. |
| **주제** | 학습자가 고른 도메인 1개가 첫 주제. 주제 안에서 짧은 턴 편(2~5단어) → 긴 턴 편(3~8단어) 순. 주제은 SNS·1:1 채팅·데이팅앱 장면을 많이 품는다. |
| **연쇄** | 다음 편의 턴은 앞 편 단어 1~2개를 다시 쓰고, 새 단어는 턴당 3개 이하. R 구간 누적 어휘 안에서만. 검사기가 센다. |

### 2-2. 주제 안의 편 순서(R1)

```

주제 1 긴  편 b1~b6  : 턴 3~8단어, 6~8턴, 앞 편 단어 재사용
```

R1 전체 = 서바이벌 3 + 주제 3개 × 16편 = **51편 ≈ 330턴**(편당 6~8턴). R2 = 주제 7개 × (8~12턴 × 8편) ≈ 56편 ≈ 560턴. R3·R4 = 주제 7개 × (12~16턴 × 6편) ≈ 84편 ≈ 1,100턴. 합 ≈ 190편 2,000턴(공통 원칙 §3 턴 수 그대로).

### 2-3. 인물·관계·말투

- A = 학습자. **글로벌 앱이므로 국적·이름을 한국인으로 고정하지 않는다**(사용자 지시 2026-11-02): 프로필 변수 `{name}`·`{country}`·`{city}`·`{lang}`(모국어)로만 등장하고, 본문에 '韓国の人?' 같은 국적 고정 대사를 쓰지 않는다(→ `{country}の人?`). 성별은 1인칭·어미 치환(僕/私), 성별판은 **일본어는 한 판**(공통 원칙 §6). 한국어 설명·번역(ko)은 공통 원칙 §8 대로 먼저 쓰되, 편 JSON 에 `en`·`zh`(표시 언어 4종) 자리를 비워 두어 나중에 채운다.
- B = 상대. 주제마다 고정 1명(친구 주제: 유카, 사랑 주제: 사쿠라, 일 주제: 다나카 선배…), 조연 C.
- 말투(§5): 낯선 사이·가게·일 = です·ます / 친구·연인 = 반말, **전환 편**(친구 주제 a4 "타메구치로 해도 돼?")을 둔다. 채팅은 처음부터 반말+ 줄임.
- 반전 1회/편(§9): 말실수+정정·읽씹 반전·갑작스러운 고백·의외 사실. `twist` 태그.
- 수위(§10): iOS 12+. 데이팅 편은 설렘·질투·밀당까지, 성적 묘사 없음, `flags`.

- 표 열: `expr, kana, rd, ko, register(반/정/채팅), region, scene(리액션·말걸기·인사·메타·채팅·약속·감정·거절), note(언제 쓰나 한 줄), min_count_r1(R1 전체에서 최소 등장 횟수: 리액션 3·말걸기 2·인사 2·메타 2)`.

### ④ 채팅 편 비율

### ⑤ 한글 독음 표기표(`docs/RD_RULES_JA.md`) 초안 원칙
- 음절 단위 한글, 장음 = 모음 한 번 더(おはよう→오하요-? 아니고 **오하요오**), 촉음 っ = 받침 ㅅ(ちょっと→촛토), 撥音 ん = 받침 ㄴ/ㅁ/ㅇ(뒤 자음 따라: さんぽ→삼포, まんが→망가, 그 밖 ㄴ), 조사 は→와, へ→에, を→오, 어두 か행·た행은 거센소리 없이(かき→카키 ✗ → **가키**는 혼동 → 통일안: 어두도 ㅋ·ㅌ 사용 '카키·타베루' — th·vi 앱과 같은 '소리 나는 대로' 원칙), ず/づ→즈, つ→츠, ふ→후, 요음(きゃ→캬), 장음 부호 ー(カタカナ)=모음 반복.
- 외래어·고유명사는 일본식 발음대로(コーヒー→코-히-? → **코오히이**), 숫자는 읽기(１０時→주우지).
- 다른 앱(th·vi·mn)의 표기표와 열 이름을 맞춰 한 폴더(`docs/RD_RULES_<lang>.md`)에, 검사기는 허용 자모·장음·받침 규칙만 기계 검사.
