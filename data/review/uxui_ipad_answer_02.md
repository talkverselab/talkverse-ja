B. 성과 달성 표시 — 시안 ③에 적용
① 무엇을 세고, 무엇은 세지 말 것인가
세는 것 (학습 설계와 맞음)
편 완주(「모든 문장 듣기」 끝까지 재생 또는 카드 세션 완료)
라이트너 단계 상승·졸업 (7단계 → 8단계 졸업)
핵심 표현 2–3개 카드의 맞음/틀림 (오늘 목표에 따라 핵심만 또는 전부)
한자 팝업을 열어본 고유 글자 수 (중복 제외)
빈도 커버율: 학습자가 마스터(또는 높은 단계)한 단어가 일본어 사용 빈도 상위 N%를 얼마나 덮는지
세지 않는 것 (과잉 게임화 금지)
단순 앱 오픈 횟수, 연속 로그인(스트릭), 포인트·배지 남발, 경쟁 순위, 의미 없는 클릭 수.
편을 여러 번 반복한 횟수 자체는 세지 않고, “다시 듣고 싶다”는 행동만 가볍게 기록.
원리: 언어 학습 앱과 습관 앱에서 지속을 만드는 것은 “오늘의 작은 완성”과 “누적된 의미 있는 진척”이지, 숫자 자체의 폭주가 아닙니다. 게임의 보상 루프는 빌려오되, 학습 흐름(떠올리기 → 맞음/틀림 → 복습)을 방해하지 않는 선에서만 사용합니다.
② 어디에 어떻게 보이는지 (데스크 레이아웃)
홈 첫 화면 (배우기 탭, 왼쪽 칸 상단 또는 오른쪽 빈 공간): 오늘의 작은 성과 카드 1장 — “오늘 편 1개 완주” 또는 “복습 카드 5장 졸업”. 큰 숫자 대신 짧은 문장 + 작은 진행 막대.
편 끝: 재생 패널 하단 또는 오른쪽 칸 하단에 순간 연출 후 작은 요약 카드 (“이 편의 핵심 표현 3개 중 2개 마스터”).
복습 끝: 라이트너 세션 종료 시 오른쪽 칸에 “오늘 졸업한 카드” 요약.
「나」 탭: 누적 성과의 본진. 섬별 진행, 레벨별 완주 수, 라이트너 분포, 빈도 커버율을 데스크처럼 카드로 배치.
③ 편 1개를 끝냈을 때의 순간 연출

점토 장면 그림이 살짝 확대되며 부드러운 금색 빛(구리 그라데이션)이 한 번 스치고, 짧은 따뜻한 효과음(0.8초)과 함께 “한 장면을 마쳤어요” 문구가 페이드인. 과도한 폭죽이나 사운드 폭주는 없음.

④ 주·월 단위 되돌아보기 화면

「나」 탭 안에 “이번 주” / “이번 달” 탭.

주간: 완주한 편 수, 졸업한 카드 수, 새로 본 한자 수, 빈도 커버율 변화(+0.3%p 등).
월간: 섬별 히트맵 스타일 진행, “가장 많이 들은 등장인물”, 레벨 전환 기록.
숫자보다 “이번 달에 여행 섬의 왕초보를 거의 다 읽었어요” 같은 문장 요약을 위에 둠.
⑤ 빈도 커버율 % 표현법

숫자만 던지지 않고 의미를 붙입니다.

예: “내가 아는 단어로 일상 일본어의 약 42%를 이해할 수 있어요”

또는 “상위 1,000개 단어 중 310개를 안정적으로 기억하고 있어요 (커버 31%)”.

작은 원형 진행 또는 수평 막대 옆에 문장을 배치하고, 다음 목표(“50%까지 12개 더”)를 부드럽게 표시. 절벽 단어(294/437/998/2500)는 구간별 마일스톤으로만 사용.

AchievementDesk (나 탭 본문: IslandProgressGrid + LeitnerDistribution + CoverageMeter)
WeeklyMonthlyReview (나 탭 하위)
데이터: 편 완주 이벤트, 카드 단계 변화, 한자 조회 집합, 단어 마스터 집합 → 커버율 계산 서비스.
위젯은 기존 데스크 Pane 안에 카드로 삽입. 폰에서는 카드가 세로로 쌓임.
「나」 탭 성과 영역 와이어프레임

C. 유료 메뉴 「맞춤 회화 만들기」 — 시안 ③ 배치
① 메뉴 위치와 진입 카드

배우기 탭 홈(왼쪽 칸 또는 오른쪽 빈 공간 상단)에 특별 카드로 배치. 레일 맨 아래나 섬 목록 맨 위에도 작은 진입점을 둠.

카드 모양: 기존 섬 카드와 같은 데스크 스타일이되, 구리 그라데이션 테두리 + “나만의 회화” 문구 + 점토풍 작은 아이콘. “첫 1편 무료”를 카드 하단에 작게 표시.

② 3단계 입력 화면

아이패드 가로: 데스크 레이아웃 활용. 왼쪽 칸에 진행 단계 표시(도메인 → 상황 → 레벨), 오른쪽 큰 칸에 현재 단계 내용.

1단계: 섬 8개 카드 그리드 (선택 시 인디고 강조)
2단계: 자유 입력 텍스트 필드 + 추천 상황 칩 (예: “카페에서 주문”, “친구와 약속”)
3단계: 레벨 4개 선택 카드 (왕초보·초보·중급·고급)
폰 세로: 단계별 풀스크린 위저드. 상단 진행 바, 하단 다음 버튼. 도메인은 가로 스크롤 카드, 상황은 칩+입력, 레벨은 세로 리스트.
③ “만드는 중” 상태

요청 즉시 서버에 ID 저장 후, 앱은 “내 맞춤 회화” 서랍에 “만드는 중” 카드로 표시.

기다리는 동안: 점토 장면이 천천히 그려지는 듯한 부드러운 애니메이션 + “초안을 쓰고 있어요” → “다듬고 있어요” → “검수 중” 단계 문구. 완성되면 푸시 또는 앱 내 배지 + 카드가 “완성”으로 바뀌며 바로 재생 가능. 몇 분~수십 분이므로 앱을 닫아도 됨을 안내.

④ 「내 맞춤 회화」 서랍과 기존 섬 편 구분

배우기 탭 안에 “내 맞춤 회화” 전용 서랍(또는 필터). 기존 섬 편과 시각적으로 구분: 카드 왼쪽 상단에 작은 “맞춤” 배지(구리색), 또는 별도 섹션. 구조가 동일하므로 재생 패널·그림 카드·라이트너에 그대로 들어감. 서랍 안에서는 최신순 또는 도메인별 정렬.

⑤ 무료 1회 → 유료 전환 안내 톤

강요 없이.

첫 편 완성 후 또는 두 번째 시도 시: “첫 맞춤 회화는 무료로 만들어 드렸어요. 다음부터는 유료예요. 계속 만들고 싶으시면 언제든 말씀해 주세요.”

톤은 따뜻하고 간결. 가격은 별도 화면에서 명확히, 선택권은 학습자에게.

⑥ Flutter 구현 메모 (구조만)
CustomDialogueEntryCard (홈 진입)
CustomDialogueWizard (3단계: DomainSelectPane + SituationInputPane + LevelSelectPane) — 아이패드에서 Pane, 폰에서 PageView
CustomDialogueDrawer (목록: MakingCard / CompletedCard)
상태: ID 기반 폴링 또는 웹소켓으로 완성 감지 → 기존 Dialogue 모델에 매핑.
위젯은 기존 데스크 Scaffold 안에 삽입. 비동기 작업은 백그라운드 서비스 + 로컬 알림.
입력 화면 + 만드는 중 + 서랍 와이어프레임
