[UX01] 일본어 학습 앱 「일본어 유니버스」(Flutter, 공개 저장소 https://github.com/talkverselab/talkverse-ja )의 **아이패드·갤럭시탭·폴드 펼침(가로 720pt 이상) UX/UI 를 완전히 새로 설계**해 주세요. 시안 3개를 서로 다른 방향으로 주세요. 이 프로젝트 「talkverse UXUI」가 그 작업 공간입니다.

## 지금 상태(저장소에서 직접 확인 가능)
- 탭 4개: 배우기·복습·탐색·나 (lib/screens/main_screen.dart). 넓은 화면은 왼쪽 레일+목록, 오른쭉 칸(lib/core/pane.dart `openPane`/`openFull`, docs/TWO_PANE_UX.md).
- 톤: 흰 바탕 · 남색 글자 #0A2540 · 구리 #B77548 → 황갈 #C19E6D 그라데이션 포인트 · 인디고 #635BFF (lib/core/theme.dart, https://talkverse.uk/talkverse/lang/ja 의 「일본어」 워드마크와 같은 톤). 이 색은 유지하되 배치·형태는 전부 바꿔도 됩니다.
- 콘텐츠: 주제(도메인 8개: 서바이벌·친구·사랑·생활·여행·문화·일·학업) × 레벨(R0 왕초보 / R1 초보 기본 / R2 / R3 / R4) 회화 JSON — assets/data/dialogues/README.md, 157편. 턴마다 일본어·가나·한글 독음·한국어·노트·태그. 등장인물 고정(유카·사쿠라·켄·리쿠·점원…), 앞 편 대사 콜백.
- 새 화면(아직 디자인 전, 기능만): lib/screens/dialogue_screen.dart(주제→편→편 화면, 맨 위 「▶ 모든 문장 듣기」), lib/widgets/episode_play_pane.dart(순차 TTS 재생 패널: 아이패드는 오른쪽 칸 = 위 그림 / 아래 문장, 배속·자막 단계 ja/かな/독음/한국어 토글, 현재 턴 강조), lib/screens/dialogue_card_screen.dart(앞면 그림만 → 탭하면 문장), 한자 팝업(lib/widgets/selectable_ja_text.dart — 한자 누르면 글자 형성·소리 가족·그림), 복습 탭 라이트너 7단계(lib/review).
- 그림: 장면 그림은 곧 만화 한 컷 스타일(부드러운 3D 점토풍)로 들어옵니다. 지금은 단어 그림(512px webp)만 있음.
- 학습 설계: 그림·떠올리기식 — 앞면은 학습자 언어(한국어)+그림, 외국어를 떠올린다; 틀림/맞음 2단계; 오늘 목표(핵심 표현만 / 전부)로 자막 단계를 줄인다.

## 요청
**시안 3개**, 각각 다른 콘셉트로(예: ① 만화책/웹툰처럼 장면 그림이 주인공인 읽기형, ② 메신저/SNS 화면을 그대로 옮긴 채팅형, ③ 공책+카드 데스크처럼 두 칸을 자유롭게 쓰는 학습데스크형 — 이건 예시일 뿐 더 좋은 방향이 있으면 바꾸세요). 시안마다:
1. 콘셉트 한 문단 + 왜 일본어 학습자(한국·글로벌)가 매일 열고 싶어지는지.
2. 아이패드 가로 화면 **와이어프레임 이미지 1장**(이미지 생성 도구로 그려 주세요: 홈/주제 목록 → 편 화면 → 「모든 문장 듣기」 재생 화면 3장면이 한 이미지에 보이게) + 세로 모드 한 줄 설명.
3. 화면 흐름(네비게이션 맵): 탭/레일 구성, 주제→편→재생/카드/한자 팝업까지.
4. 핵심 컴포넌트 명세: 재생 패널(그림 칸 비율, 현재 턴 강조, 컨트롤 위치), 그림 카드, 한자 팝업, 라이트너 「오늘의 복습」 카드, 레벨 전환(왕초보↔초보) 위치.
5. 타이포·간격·모션 규칙(톤 색은 유지), 다크 모드 대응 한 줄.
6. Flutter 구현 메모: 바꿀 파일과 새 위젯 트리 개요(코드는 쓰지 말고 구조만), 폰(세로 한 칸)으로 줄일 때의 규칙.
마지막에 **3개 비교표**(강점·약점·구현 난이도·추천 순위)와 당신의 1순위 추천 이유.
답은 한국어로. 실제 작품명·브랜드는 쓰지 말고, 이 앱 톤 안에서만.
