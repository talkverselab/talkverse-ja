시안 01 — 학습 데스크형 (공책 + 장면 카드)
1. 콘셉트

넓은 화면을 「내 책상 위 일본어 공책」으로 재구성한다. 왼쪽 레일은 탭, 가운데는 섬·편 목록(공책 인덱스), 오른쪽은 오늘의 장면 카드와 문장. 장면은 부드러운 3D 점토풍 1컷으로 고정 캐릭터(유카·사쿠라·켄·리쿠 등)가 계속 등장해 이야기의 연속성을 준다. 학습자는 매일 이 책상을 열고, 어제 읽던 편을 이어서 보고, 커버율 숫자가 조용히 올라가는 것을 확인하며, 편 끝의 짧은 구리빛 연출로 하루를 닫는다. 스트릭·포인트 대신 “내가 아는 단어로 일상 일본어의 ○○%를 이해”라는 실질 성과가 매일 열어보고 싶어지는 이유다.

2. 와이어프레임 이미지

아이패드 가로 3장면 한 장: 홈(배우기) / 편 화면 / 모든 문장 듣기 재생. 흰 바탕 · 남색 #0A2540 · 구리 #B77548 포인트.

4. 네비게이션 맵

레일(배우기·복습·탐색·나)

→ 배우기: 기초(50음도·조사·한자 배우기 격자·한자 단계 퀴즈) / 회화(섬 8개 × 레벨 R0~R4) / 단어 / 옛 에피소드

→ 섬 → 편 목록 → 편 화면 (문장 목록 + 장면 카드)

→ 재생(모든 문장 듣기) · 그림 카드 · 한자 팝업(문장 내 한자 탭)

→ 복습(오늘의 복습 카드) · 나(성과)

한자 배우기: 기초 안, 아이패드 = 왼쪽 20자 격자 + 오른쪽 글자 정보

맞춤 회화: 회화 섬 목록 하단 또는 오늘의 데스크에서 진입, 완료 후 서랍

5. 핵심 컴포넌트 명세
재생 패널: 위 60% 장면 그림(16:9 또는 4:3 고정), 아래 문장 리스트. 현재 턴 구리 테두리 + 자동 스크롤. 컨트롤 하단 고정: 재생/일시정지, 배속, 자막 단계 토글(日本語/かな/독음/한국어). 현재 턴 강조.
그림 카드: 점토풍 1컷. 편 화면 오른쪽 상단, 재생 화면 상단. 탭 시 살짝 확대.
한자 배우기: 왼쪽 격자(20자) + 오른쪽 상세(훈음·형성·팁·어원·그림). 단계 완료 시 구리 플래시.
한자 팝업: 문장 내 한자 탭 → 하단 시트 또는 오른쪽 오버레이. 훈음·읽기·형성·팁·어원·소리 가족·그림·대표 단어·읽기별 단어.
오늘의 복습 카드: 앞면 한국어+그림, 뒷면 일본어. 7단계 라이트너. 틀림/맞음 2단계. 아이패드 가운데 또는 전체.
레벨 전환: 섬 목록 상단 또는 편 목록 상단에 R0~R4 세그먼트.
성과 카드:
홈: 오늘의 목표 + 커버율 작은 카드
편 끝: 그림 살짝 확대 + 구리빛 한 번 + 0.8초 소리 (폭죽 없음)
「나」: 섬별·레벨별·라이트너 분포·커버율·주/월 요약
센다: 편 완주, 라이트너 상승/졸업, 핵심 표현 맞음, 한자 팝업 본 글자 수, 커버율
안 센다: 오픈, 스트릭, 포인트, 순위
6. 타이포·간격·모션
타이포: 남색 #0A2540 기본, 제목 20~24pt bold, 본문 16~18pt, 보조 12~14pt. 일본어는 약간 큰 사이즈.
간격: 8pt 그리드. 카드 패딩 16pt, 섹션 간격 24pt.
모션: 페이지 전환 300ms ease, 카드 플립 200ms, 편 끝 연출 0.8초 (확대 1.05 + 구리 오버레이 페이드).
다크 모드: 배경 #0A2540, 글자 밝은 회, 구리 포인트 유지, 그림 카드 약간 어둡게.
