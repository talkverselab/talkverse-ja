[UX03] 일본어 학습 앱 「일본어 유니버스」(Flutter, 공개 저장소 https://github.com/talkverselab/talkverse-ja , 최신 커밋 기준)의 **아이패드·갤럭시탭·폴드 펼침(가로 720pt 이상) UX/UI 를 완전히 새로 설계**해 주세요. **서로 다른 콘셉트의 시안 3개.** 이 방은 새로 만든 작업 공간입니다(이전 대화 없음). 이번 답에는 **이미지를 넣지 마세요** — 글 + 텍스트 레이아웃(ASCII 박스)으로만. 그림은 나중에 한 장씩 따로 부탁드립니다.

## 지금 앱(저장소에서 확인 가능)
- 탭 4개 배우기·복습·탐색·나(lib/screens/main_screen.dart). 넓은 화면 = 왼쪽 레일 + 왼쪽 목록 칸 + 오른쪽 내용 칸(lib/core/pane.dart `openPane`/`openFull`, docs/TWO_PANE_UX.md). 학습·퀴즈·재생은 전체 화면.
- 톤: 흰 바탕 · 남색 글자 #0A2540 · 구리 #B77548 → 황갈 #C19E6D 그라데이션 포인트 · 인디고 #635BFF(lib/core/theme.dart, https://talkverse.uk/talkverse/lang/ja 워드마크와 같은 톤). 색은 유지, 배치·형태는 전부 바꿔도 됩니다.
- 배우기 탭 내용: ① 기초(50음도·조사·**한자 배우기**(lib/screens/kanji_learn_screen.dart — 단계 20자를 한 글자씩 보고 → 문제; 아이패드 = 왼쪽 20자 격자 + 오른쪽 글자 정보)·한자 단계 퀴즈) ② 회화(새): 섬별 회화 R0~R4(lib/screens/dialogue_screen.dart — 섬 8개 서바이벌·친구·사랑·생활·여행·문화·일·학업 × 레벨 R0 왕초보/R1 초보 기본/R2/R3/R4, 241편, 편 화면 맨 위 「▶ 모든 문장 듣기」 → lib/widgets/episode_play_pane.dart 순차 TTS 재생 패널: 아이패드 오른쪽 칸 = 위 장면 그림 / 아래 문장, 배속·자막 단계 日本語/かな/독음/한국어 토글, 현재 턴 강조) + **맞춤 회화 만들기**(lib/screens/custom_script_screen.dart — 섬·상황·레벨을 고르면 서버가 몇 분 뒤 나만의 1편을 만들어 「내 맞춤 회화」 서랍에 넣음, 첫 1편 무료·이후 유료) ③ 단어(절벽 단어 R1~R4·필수 단어·JLPT 단어, 그림 플래시카드) ④ 옛 에피소드 L1~L3.
- 복습 탭: 라이트너 7단계(1·2·4·8·16·32·64일, 8단계 졸업) 「오늘의 복습」 카드(lib/review). 카드 앞면 = 한국어+그림, 뒷면 = 일본어.
- 한자 팝업(lib/widgets/selectable_ja_text.dart): 회화 속 한자를 탭 → 훈음·읽기·글자 형성(부품+부품, 소리 부품 강조)·외우는 팁·어원·소리 가족·그림·대표 단어·읽기별 단어.
- 그림: 단어 그림(512px webp) 있음. 장면 그림은 곧 만화 1컷(부드러운 3D 점토풍)으로 들어옴.
- 학습 설계: 플루언트 포에버식(앞면 학습자 언어+그림 → 외국어 떠올리기, 틀림/맞음 2단계, 오늘 목표에 따라 자막 단계 줄이기). 등장인물 고정(유카·사쿠라·켄·리쿠·점원…), 앞 편 대사 콜백.
- 성과 표시(아직 미구현, 설계 원칙 확정): **센다** = 편 완주·라이트너 단계 상승/졸업·핵심 표현 맞음·한자 팝업으로 본 고유 글자 수·빈도 커버율("내가 아는 단어로 일상 일본어의 약 42%를 이해") / **안 센다** = 앱 오픈·스트릭·포인트·순위. 편 끝에는 짧은 순간 연출(그림 살짝 확대 + 구리빛 한 번 + 0.8초 소리, 폭죽 없음). 「나」 탭 = 섬별 진행·레벨별 완주·라이트너 분포·커버율·주/월 되돌아보기.

## 요청 — 시안 3개(각각 다른 콘셉트; 예: 만화책 읽기형 / 메신저·채팅형 / 공책+카드 학습데스크형 — 더 좋은 방향이 있으면 바꾸세요)
시안마다:
1. 콘셉트 한 문단 + 왜 학습자(한국·글로벌)가 매일 열고 싶어지는지.
2. **아이패드 가로 텍스트 레이아웃(ASCII 박스) 3장면**: 홈(배우기 첫 화면) / 편 화면 / 「모든 문장 듣기」 재생 화면. 세로 모드·폰 한 줄씩.
3. 네비게이션 맵: 레일·탭 → 섬 → 편 → 재생·그림 카드·한자 팝업 → 복습·「나」까지. **한자 배우기**와 **맞춤 회화 만들기**의 진입 위치 포함.
4. 핵심 컴포넌트 명세: 재생 패널(그림 비율·현재 턴·컨트롤 위치), 그림 카드, 한자 팝업/한자 배우기 화면, 「오늘의 복습」 카드, 레벨 전환(왕초보↔초보) 위치, 성과 카드(홈·편 끝·「나」 탭)와 편 끝 순간 연출, 맞춤 회화 입력 3단계·만드는 중·서랍.
5. 타이포·간격·모션 규칙(톤 색 유지), 다크 모드 한 줄.
6. Flutter 구현 메모(코드 없이 구조만): 바꿀 파일·새 위젯 트리, 폰(세로 한 칸)으로 줄이는 규칙.
마지막에 **3개 비교표**(강점·약점·구현 난이도·추천 순위)와 1순위 추천 이유. 답은 한국어, 실제 작품명·브랜드 금지.
