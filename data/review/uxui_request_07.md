## 지금 단어 메뉴(lib/screens/*)
- 배우기 탭 「단어」 섹션: 절벽 단어 R1~R4(`word_freq_screen.dart` — 순위·누적% 표 같은 목록, 2,500어, 탭하면 TTS) / 필수 단어(`topic_vocab_screen.dart` — 주제별 975어, 목록·격자, 외우기 모드) / JLPT 단어(`jlpt_words_screen.dart` — 8,600어, 후리가나). 플래시카드(`flashcard_screen.dart` — 앞면 한국어+그림 → 일본어, 틀림/맞음). 전부 글자 위주, 표처럼 보임.
- **단어 그림 DB**(점토 톤 512px, 파스텔 배경·펠트 인형·글자 없음)가 있고 늘어나는 중(지금 377장, 절벽 R1 294어부터 전부 채우는 중). 그림이 있는 단어는 썸네일로 보여 줄 수 있음.
- 라이트너 복습(7단계)·성과(빈도 커버율 "내가 아는 단어로 일상 일본어의 N%")와 연결돼 있음. 절벽 = 빈도 순위 ≤294/≤437/≤998/≤2500 구간.

## 요청(시안 1개)
그림이 주인공인 단어장: ① 홈(배우기 「단어」 섹션을 대신할 단어 메뉴 첫 화면) ② 단어 목록/격자(그림 카드 격자, 절벽 구간·주제 전환, 아는 단어 표시, 라이트너 단계 표시) ③ 단어 1개 상세(그림 크게 + 단어·읽기·뜻·예문·이 단어가 나온 회화 편으로 가기·「복습에 넣기」). 아이패드 가로(왼쪽 목록·오른쪽 상세)와 폰. 플루언트 같은 특정 학습서 이름·브랜드 언급 금지. 섬이 아니라 「주제」. 톤: 흰 바탕·남색 #0A2540·구리 #B77548→황갈 #C19E6D·인디고 #635BFF.
답 형식: 콘셉트 한 문단 → **이미지 1장(아이패드 가로 한 프레임: 단어 격자 + 오른쪽 단어 상세)** → ASCII 레이아웃 3장면 → 컴포넌트 명세 → Flutter 메모(파일·위젯 구조만). 첫 줄에 "푸시 불가"면 그대로, 마지막 줄 "단어 시안 완료".
