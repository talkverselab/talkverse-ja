# 일본어 절벽구간 재산출 v2 (2026-11-03, 사용자 결정 — 한국어앱과 같은 방식)

- 말뭉치: 공개 자막 묶음에서 **일본 제작 영화·드라마만** 골라낸 대사 자막 200편(작품당 1판), 95만 토큰. 제작국 = 공개 지식 DB 「제작 국가 = 일본」 + 그 시리즈 회차. 일본어 원본 자막은 빈 파일·OCR 이 깨진 판이 많아 히라가나 비율 35% 미만·일본어 500자 미만인 판은 뺐다(쓸 만한 판 200편). 공개 저장소라 제공처 이름은 적지 않는다.
- 단위: fugashi+unidic 형태소. 조사·조동사(た·ます·ない…)를 각각 한 토큰으로 분자·분모에 넣고, 용언은 기본형(書字形基本形). 기호·숫자·로마자 제외, 고유명사·감동사 포함, 청각장애인용 소리 설명 제거.
- frequency = 토큰 ÷ 전체 토큰(가중 없음). 2,500위 최대 누적 = **89.0%**.
- 구간(**절대 기준**, 2026-11-03 사용자 지시로 19개 언어와 통일 — 누적 55·60·70·80% 에 처음 닿는 순위): **R1 = 62위(55.1%) · R2 = 96위(60.1%) · R3 = 251위(70.0%) · R4 = 778위(80.0%)**, 779~2,500위 = R5(80% 밖). 같은 날 처음 낸 최대치 비례값은 R1 107 · R2 179 · R3 603 · R4 2,500.
- 옛 표(해외 작품 일본어 자막 기성 빈도표, た·ます 누락·활용형 섞임) 대비: R1 294 → 62, R2 437 → 96, R3 998 → 251, R4 2,500 → 778, 2,500위 최대 누적 80.3% → 89.0%.
