# 일본어 절벽구간 재산출 v2 (2026-11-03, 사용자 결정 — 한국어앱과 같은 방식)

- 말뭉치: 공개 자막 묶음에서 **일본 제작 영화·드라마만** 골라낸 대사 자막 200편(작품당 1판), 95만 토큰. 제작국 = 공개 지식 DB 「제작 국가 = 일본」 + 그 시리즈 회차. 일본어 원본 자막은 빈 파일·OCR 이 깨진 판이 많아 히라가나 비율 35% 미만·일본어 500자 미만인 판은 뺐다(쓸 만한 판 200편). 공개 저장소라 제공처 이름은 적지 않는다.
- 단위: fugashi+unidic 형태소. 조사·조동사(た·ます·ない…)를 각각 한 토큰으로 분자·분모에 넣고, 용언은 기본형(書字形基本形). 기호·숫자·로마자 제외, 고유명사·감동사 포함, 청각장애인용 소리 설명 제거.
- frequency = 토큰 ÷ 전체 토큰(가중 없음). 2,500위 최대 누적 = **89.0%**.
- 구간(최대치 비례 55/60/70/80 ÷ 80): **R1 = 107위(61.3%) · R2 = 179위(66.7%) · R3 = 603위(77.9%) · R4 = 2,500위**.
- 옛 표(해외 작품 일본어 자막 기성 빈도표, た·ます 누락·활용형 섞임) 대비: R1 294 → 107, R2 437 → 179, R3 998 → 603, max 80.3% → 89.0%.
- 한계: 200편·95만 토큰으로 한국어(4,268편·2,322만)보다 작다. 표기 흔들림(言う/いう 등)은 합치지 않았다.
- 파일: `lang_ja_top2500.csv`(rank,word,pos,frequency,cum_pct,region), `ja_cliff_summary.json`. 재현: `tools/corpus/run_cliff.sh`(JA_SUB_URL 필요) 또는 `select_titles.py <zip> Q17 <목록>` → `cliff_ja.py <zip> <출력> --only <목록>`.
- **앱 데이터(assets/data/freq/lang_ja_with_regions.csv)는 아직 옛 표 그대로** — 교체 여부는 사용자 결정.
