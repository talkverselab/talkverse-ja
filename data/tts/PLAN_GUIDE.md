# 회화 음성 감정 계획 작성법

**2026-11-07 부터 감정은 회화 편 JSON 에 함께 쓴다**(사용자 지시 "회화문 만들 때 음성용 감정열을 함께", "음성 만들 때 그 감정을 쓰도록 스크립트를"). 감정 계획 `data/tts/plan/<편id>.json` 은 `tools/tts/plan_from_ep.py` 가 편 JSON 에서 자동으로 만들고, `make_jobs.py`·`run_all.py` 는 계획 파일이 없으면 스스로 만든다(`ttslib.plan`). **감정을 두 번 손으로 적지 않는다.** 2026-11-07 이전 215편은 계획 파일을 먼저 썼으므로 편 JSON 에 감정 열이 없다 — 그 편들은 계획 파일이 원본이다.

내용 보기 `python3 tools/tts/show_ep.py <편id>...`, 계획 검사 `python3 tools/tts/check_plan.py <편id>...`(새 편은 `check_dialogues.py` 가 감정 열 유무·segs 일치·neutral 과다도 본다).

## 1. 편 JSON 에 쓰는 열

```json
{"id":"r1_x_a1", "speakers":{"A":"{name}","B":"ユカ","C":"店員"},
 "cast":{"C":"woman_y"},
 "fill":{"{drama}":{"ja":"星の約束","ko":"별의 약속"}},
 "turns":[
  {"num":1,"speaker":"A","ja":"ユカ、ドラマ、おすすめある？", "emotion":"cheerful", …},
  {"num":2,"speaker":"B","ja":"えっ、本当？じゃあ見てみる。", "segs":[["surprised","えっ、本当？"],["gentle","じゃあ見てみる。"]], …},
  {"num":3,"speaker":"A","ja":"私も行く。","kana":"わたしもいく。", "emotion":"shy",
   "m":{"ja":"僕も行く。","kana":"ぼくもいく。","rd":"보쿠모 이쿠.","ko":"나도 갈게.","emotion":"shy"}, …}
 ]}
```

- **`emotion`**: 턴 전체가 한 감정일 때. 읽기(음성 모델이 읽을 글)는 `kana` 에서 지문 `（…）`·`w`·`♪`·이모지를 뺀 것이 자동으로 쓰인다.
- **`segs`**: 감정이 바뀌는 턴. `[감정, 본문]` 또는 `[감정, 본문, 읽기]` 를 말하는 순서대로. 이어 붙이면 `ja` 와 같아야 한다(공백·「…」·괄호 지문은 비교에서 무시). 같은 감정의 문장은 한 조각으로 둔다. 네 글자 미만 조각은 아주 불안정하니 턴 전체가 짧을 때 말고는 만들지 않는다.
- **읽기(세 번째 칸)**: 지문 `（笑）`·`（電話）`·`（歌う）`, 채팅의 `w`, 이모지, `♪` 는 소리로 나오면 안 되므로 뺀다. 숫자나 읽기가 갈리는 한자, 여섯 글자 이하의 짧은 조각은 히라가나로 적는다(예: 来てな → きてな). 지문만 있는 조각은 만들지 말고 다음 조각에 합친다.
- **감정 16개**: neutral polite stiff cheerful amused teasing excited surprised shout tsukkomi annoyed sad worried flustered shy gentle.
  **문장마다 대사 맥락을 보고 정한다. 밋밋하게 neutral 만 쓰지 말 것** — 점원·역무원의 안내는 polite, 츳코미는 tsukkomi, 심쿵 턴은 gentle·shy. 소리 낼 글이 없는 턴(지문·「……」)만 감정을 안 쓴다.
- **`cast`**(편 단위): A 는 쓰지 않는다(학습자, 자동). 고정 인물은 이름으로 자동 배정 — ユカ=yuka · サクラ=sakura · リク=riku · ケン=ken · ミン=min · ホセ=jose · 同僚ミサキ=misaki · 課長=kacho. **그 밖의 인물은 `cast` 에 적는다**: man_y man_m man_o woman_y woman_m woman_o(20대까지 _y, 30~50대 _m, 노인 _o), 간사이 사투리는 뒤에 `_ks`(man_m_ks 등). 없으면 변환기가 멈춘다.
- **`fill`**(편 단위): `{name}`·`{country}`·`{city}`·`{lang}` 은 그대로 둔다(자동으로 アレックス/エマ·カナダ·トロント·英語). 그 밖의 자리(`{drama}`·`{anime}`·`{idol}` 등)는 ja·ko 값을 넣는다. **실제 작품·가수·회사 이름은 금지** — 지어낸 이름만. `{lang_slowly}` 같은 영어 문구는 카타카나 발음으로, `{name_meaning}` 은 アレックス·エマ 어느 쪽에도 맞는 말로.
- **`m`·`f`**(턴 안): 기본 본문이 그 판에 어색할 때만 그 판의 전체 턴(ja·kana·rd·ko + emotion 또는 segs)을 넣는다.
  - 학습자가 격식 없이 말하는 「私」: 남성판은 「僕」. 학습자의 「僕」「俺」: 여성판은 「私」. 격식 있는 자리의 「私」는 둘 다 그대로.
  - `{name}くん`: 여성판 `{name}さん` 또는 `{name}ちゃん`. 「彼女でもおるんか」처럼 학습자의 상대를 가리키는 말: 여성판 「彼氏」. 어미(だぜ·わよ 등)와 학습자를 남자·여자로 부르는 말도 같다.
  - 고칠 때는 뜻과 재미를 유지한다. 그 밖의 줄은 건드리지 않는다. 본문 수정은 이 성별 조정만 허용한다. rd = 일본어 소리를 한글로 적은 독음, 기존 턴의 표기 방식을 따른다.

## 2. 계획 파일(자동 생성 결과) 꼴

```json
{"ep":"r1_x_a1",
 "cast":{"B":"yuka","C":"woman_y"},
 "fill":{"{drama}":{"ja":"星の約束","ko":"별의 약속"}},
 "turns":{
  "1":{"segs":[["cheerful","ユカ、ドラマ、おすすめある？","ゆか、どらま、おすすめある？"]]},
  "2":{"segs":[["surprised","えっ、本当？"],["gentle","じゃあ見てみる。"]]},
  "3":{"segs":[["shy","私も行く。","わたしもいく。"]],
       "m":{"ja":"僕も行く。","kana":"ぼくもいく。","rd":"보쿠모 이쿠.","ko":"나도 갈게.","segs":[["shy","僕も行く。","ぼくもいく。"]]}}
 }}
```

- 생성: `python3 tools/tts/plan_from_ep.py <편id>...`(이미 있으면 건너뜀, `--force` 로 덮어씀) → 바로 `check_plan.py` 가 돈다. 생성이 멈추면 메시지대로 편 JSON 을 고친다(감정 없는 턴, cast 없는 화자, segs 불일치).
- 계획 파일을 손으로 고쳐야 할 때(읽기 미세 조정 등)는 고쳐도 되지만, 그 뒤 편 JSON 의 감정 열과 어긋나지 않게 같은 값을 편 JSON 에도 반영한다. 둘이 다르면 편 JSON 이 기준이다(`--force` 로 다시 만든다).
