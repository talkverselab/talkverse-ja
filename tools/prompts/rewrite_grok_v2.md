# Grok 강화 재작성 프롬프트 v2 (2026-11-03 — 사용자 리뷰: "재미가 많이 부족하고, 너무 짧은 문장들로 이루어진 회화가 있다")

```
[{code}] 아래는 일본어 학습 앱 회화 1편의 초안입니다. 이 초안은 **문장이 너무 짧고 재미가 부족하다**는 평가를 받았습니다. 초안의 장면·인물·턴 수·각 턴의 내용과 순서·반전·{{변수}}·콜백 대사(앞 편 대사를 되살린 줄)는 그대로 두고, **각 턴을 더 살아 있는 대사로 다시 써 주세요**.
{roles} 장면: {scene}. 말투: {register}.
반드시:
① 한 턴 = 1~3문장. 짧은 추임새만인 턴은 편당 2개까지(침묵 「……」 턴은 예외). 지금 평균 {avg_chars}자 → **턴 평균 {target_chars}자 이상**. 늘리는 방법은 "설명 추가"가 아니라 **반응·되치기·구체적인 디테일**(무엇을 보고, 무엇을 들고, 어떤 표정으로).
② **코믹하게**: 인물의 성격이 대사에서 드러나고(놀리기·받아치기·엉뚱한 논리), 편에 웃음 포인트 2개 이상, 마지막 줄은 짧은 한 방.
③ 구어 추임새(それな·てか·やばい·マジで·〜じゃん 등)는 **편 전체에 3~4개, 한 턴에 최대 1개, 뜻이 꼭 맞는 자리에만**. 뜻 없이 끼워 넣기 금지 — "てかそれな、りょって返しただけなのに" 같은 문장은 실패작입니다. 교과서체·번역투·설명 대사도 금지.
④ 학습자가 **외우고 싶어지는 한 줄**을 편마다 하나 이상(짧고 리듬 있고 일상에서 그대로 쓸 수 있는 말). 각 턴의 원래 핵심 단어·학습 포인트는 남길 것.
⑤ 연애 장면이면 설렘의 여백(말을 다 하지 않고 멈추기)은 살리되 성적 묘사 금지. 실제 작품·곡·브랜드·국적 이름 금지.
⑥ 목표 표현 {targets} 은 자연스럽게 들어갈 것.
출력 형식(이것만, 다른 설명 없이): 줄마다 `번호 화자: 일본어 / 한국어(일본어 말투에 맞춘 자연스러운 한국어 구어)`. 마지막 줄에 `킥: ` 뒤에 이 편의 웃음 포인트 한 줄.
```
