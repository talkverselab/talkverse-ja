# Grok 강화 재작성 프롬프트 v2 (2026-11-03 — 사용자 리뷰: "재미가 많이 부족하고, 너무 짧은 문장들로 이루어진 회화가 있다")

v1 재작성은 초안을 거의 그대로 두는 경향이 있었다. v2 는 **초안을 소재로만 쓰고 대사를 새로 쓰라**고 요구한다. 생성 `tools/enrich_prompts.py`, 반영 `tools/apply_rewrite.py`.

```
[{code}] 아래는 일본어 학습 앱 회화 1편의 초안입니다. 이 초안은 **문장이 너무 짧고 재미가 부족하다**는 평가를 받았습니다. 초안의 장면·인물·턴 수·반전 아이디어·{{변수}}·콜백 대사(앞 편 대사를 되살린 줄)는 그대로 두고, **대사를 새로 써 주세요**.
{roles} 장면: {scene}. 말투: {register}.
반드시:
① 한 턴 = 1~3문장. 짧은 추임새만인 턴은 편당 2개까지만(침묵 「……」 턴은 예외). 지금 평균 {avg_chars}자인데 **턴 평균 {target_chars}자 이상**으로.
② **코믹하게**: 인물의 성격이 대사에서 드러나고(놀리기·받아치기·엉뚱한 논리·현실적인 사고), 편마다 웃음 포인트 2개 이상, 마지막 줄은 짧은 한 방(펀치라인).
③ 일본 사람이 지금 실제로 쓰는 구어·추임새(それな·てか·やばい·マジで·〜じゃん·〜って感じ·いや〜·ってか 등)를 턴마다 자연스럽게. 교과서체·번역투·설명 대사 금지.
④ 학습자가 **외우고 싶어지는 한 줄**을 편마다 하나 이상(짧고 리듬 있고, 일상에서 그대로 쓸 수 있는 말).
⑤ 연애 장면이면 설렘·두근거림의 여백(말을 다 하지 않고 멈추기)은 살리되 성적 묘사 금지. 실제 작품·곡·브랜드·국적 이름 금지.
⑥ 목표 표현 {targets} 이 자연스럽게 들어갈 것.
출력 형식(이것만): 줄마다 `번호 화자: 일본어 / 한국어(일본어 말투에 맞춘 자연스러운 한국어 구어)`. 마지막 줄에 `킥: ` 뒤에 이 편의 웃음 포인트 한 줄.

초안:
{lines}
```
